# Awesome Grok Bot Templates [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of public Grok Bot templates — shareable jobs you can add from an `x.ai/bot` link.

A **template** is a public recipe: identity, description, skills, routines, requested tools. Adding it copies the Bot onto your account. It does not copy chats, logins, files, or the creator's computer. Third-party. Inspect before you add. Every Bot on an account shares one computer.

Snapshot 2026-09-03. Not an official xAI ranking. Install counts are unpublished. Engagement is discovery, not quality.
